General Knowledge

Functions are a way to repeat actions with tons of code. They have the ability to contain code that can make/do something. You can write the code inside the function, and then call it back with the function name, along with parameters. Parameters are like input variables that can change what is inside the code. For example, if the function said: function math(x){x + 1} and I called math(20), the funciton would return 21. If I put any other number it would input that number. Doing this allows the function to be way more flexible than what it could originally do.
