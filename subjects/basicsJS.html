General Knowledge

Javascript is a coding language that is very popular among web developers. It allows for quick coding that allows websites to have functionality behind the HTML and CSS such as a search bar or making todo lists. It is very useful and can be found in almost any corner of the internet. It is fairly simple as well and doesnt take too many basic concepts to get going with it.

It can store and use information from the HTML or CSS and has the capability to transfer it across other pages. There are "global" ways to do this, which can keep information on a higher level (and can be used anywhere), versus a "local" version of this, which can only be used within specific lines of code or just on the page itself. These are called variables, and they are the backbone of JS. Everything uses them in some form.

All types of code can be used with the other types. Arrays hold information such as strings and integers, and can be changed and shuffled around. Condtionals are a way to run code based on if something is true, or has a certain value. There are many different ways to use them, as with everything else. The DOM can edit HTML based on user inputs or based certain conditions just like conditionals. Functions can hold lines of code to be used for later. Loops can repeat code and can list through arrays.

Variables

Variables are a way to store and use information. You can set it equal to something, and if you need that number later, it will be there in the form of the variable. There are 3 main ways to write it: var, let and const. var is the oldest and can be declared or assigned to something else at any point in time. let is about the same, except that it cant be redeclared, you will need a new variable. const is for something you dont want to be changed at all. It cannot be updated or redeclared like the other two.

It is best to use const for things that shouldnt be changed and let for everything else

Math and Operations

JS supports basic math to be done within its code. You can do addition(+), subtraction(-), multiplication(*) and division(/). There is also something called "mod"(%)which finds the remainder of a certain operation. Math can be stored within a variable because the variable will keep the product of whatever the operation is. This means you can have entire equations as variables, or do math with variables.

Since you can change around variables (only var and let), you can add and subtract from them. This is very common in loops and conditionals. The best way to do it is with the shortcut: +=. This adds the following number/variable onto the original variable. For example, if var showing was equal to 2: var showing += 3 this would make showing equal to 5

Strings

Strings are a way to have words in JS. They can hold letters instead of numbers, and can be placed into variables. They must be wrapped in quotes in order for JS to recognize them. They can be placed in variables or arrays, and are very useful for printing things out in the DOM. They can be put together through conecactanation. By writing out the string, either inside its variable or on its own, you can write: console.log(string1 + " the addon"). The console will show whatever is in string 1 and have " the addon" afterwards. It is very important you have a space in the second string, otherwise they will be smushed together

You can also take different pieces of a string. Using string1.substring(), you can take a piece of the string inside string1. Since each character is counted from 0, taking the first 3 letters of string1 would look like: console.log(string1.substring(0, 4)). The last number is the value of the letter that you dont want since it is offset by 1. You can also use .repeat() to repeat the string without having to rewrite it each time. You can input the amount of times you want it to be repeated, either manually or with a variable. It can be used as: string1.repeat(n). n can be a certain number, and string1 will repeat by n times. For Loops are useful for counting n
