Concepts

The DOM allows you to change elements on the page using HTML, as well as add functionality to things like buttons using JS.

Basics

document.querySelector("element") Can select an element by its id or its tag. For example, if I wanted to select this paragraph, I could type in document.querySelector("p"). It is usually used to select something for a later command to change.

.innerHTML Can take the HTML of an element by attaching it to the previous code. It has the ability to change the HTML inside of the selected element. For example: document.querySelector("p").innerHTML will show whats inside a paragraph. You can change or edit the code using .innerHTML =/+=The regular equal will just change the code/text but the plus equal will add on to it at the end. It doesnt need to be attached to a selector, and works the same if that element is saved in a variable or has an ID attached to it

Style

.style.property can change the CSS values of an element by attaching it to a document.querySelector or a variable containing HTML. For example: document.querySelector("p").style.fontSize = "20px" would change the font size of this paragraph to 20 pixels instead of its default amount. The CSS is almost the exact same except for the naming. Instead of using dashes to seperate words, just put it in camelCase as shown here. The actual value always has to be in quotes as well.

Class List

.classList can be very useful. On its own, it can only show what classes are attached to a certain selected element, however it has multiple addons that can change this.

If you attach .add("class"), it can add on the specified class to the HTML, which can be used to quickly change CSS without conflicts or extra effort. You can also use .remove("class") to take out a class from the selected element. Both of these addons are simalair to the .push and .pop code from arrays.

.toggle("class") is a true or false addon, and works like a lightswitch. It checks if the selected element has a certain class. If it doesnt have the class, it adds it on. If it does, it turns it off.

All 3 of these addons can be used on the same line on the same element, but its better to have it seperate for readability

Creating

document.createElement("element") is a quick way to make a new element. It is good for doing something quickly in JS without having to go back up to the HTML code and make something new. For text, you can use it with .innerHTML to make new paragraphs or text boxes appear. Save this in a variable

document.querySelector("element").appendChild(variable) can attach a created Element to the end of an exsisting one. For example: document.querySelector("p").appendChild(newText) would add on whatever is in the variable "newText" to the very back of the first paragraph. On the other hand, .inesertBefore("element","childID") can insert the new variable to the front of an element. You have to select what element you want to insert it in, and then the element, and then plug in the ID/variable of what you want to insert in.

childID needs either a separate variable var child= document.querySelector(#ID) or it can be another document.querySelector. All querySelectors can technically be replaced by a variable for better readability but is not necesary

Bulk Editing

.querySelectorAll("element") can select every single selected element with the same type or class. It puts each element into an array for later use. For example: document.querySelectorAll("p") would select every paragraph on the page whether it has any other identification or not.

.forEach(function(parameter, index){code}) is simalair to a for loop. It will go through the array of the chosen element and apply the code to each one using the index and parameter.

var paragraphs = document.querySelectorAll("p") paragraphs.forEach(function(words, i){if(i % 2 == 0){paragraphs.style.color = "green"}})

This goes through each paragraph selected, and turns every second paragraph green using the index.

Events

.addEventListener("event", function(parameter){}) can be assigned to an element so that it can "listen" for a certain event. For example, you could tell it to listen for a click. When it clicks, the function would run. It is easiset to write the function there instead of defining it somewhere else. Any JS code will work inside of the function

document.querySelector("p").addEventListener("keypress", function(){if(keypress == "a"){ console.log("You pressed a")})

This makes it possible to have things change based on a certain user input, which adds a lot of functionality to a lot of things

Input Checkers

Every input that you make can be recognzied by the computer and put in the console. You can access the inputs information by using .value. This is for text only. This can check the letters that you type in, and the entire string when you are finished. For collecting multiple different text inputs you can iterate and do the same using event.target.value

.checked will check if a radio button is selected by the user. This only works if its selected button is pressed. To check all of them at once, use document.querySelector(“input[name = ‘IDname’]:checked”)IDname is not the same as id. This will check all radio buttons with the same name as each other
