General Knowledge

Arrays are a way to hold multiple different variables, strings or numbers. They are basically a dynamic list that can be used and changed as needed. The way to have a list without arrays would be to have each value in a seperate value such as: value1= 1 value2 = 2, but an array can hold both of these in one variable by: array= [1, 2, 3]. To access each value, write: array1[1] This gets the second value because an array counts from 0.

Editing Arrays

There are a few different ways to change an array. They are best used with conditionals and functions so that they can be repeated

  • array.push([]) adds onto the back of the array
  • array.unshift([]) adds onto the front of the array
  • array.pop([]) takes away from the back of the array
  • array.shift([]) take away from the front of the array

Nested Arrays

Arrays can contain extra arrays within itself. There can be as many different arrays as you want, and they all act the same way. To access it, write: array1[first array index][nested array index]. The first index gets the array position, and then the second index gets the value of whatever you are searching for in the nested array.

.split([i]) can take a specific element out of an array and saves it somewhere else. This is best used with a variable to access it easier
